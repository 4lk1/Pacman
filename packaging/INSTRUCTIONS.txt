PAC-MAN - Ghosts! More ghosts!
==============================

HOW TO RUN
    Windows/macOS/Linux: double-click "pacman" (or run it from a
    terminal). The game needs a configuration file:
        pacman config.json
    If no argument is given, the game asks for one. The config file is
    JSON with comments (lines starting with # or // are ignored).

CONTROLS
    Move .............. Arrow keys or WASD
    Pause / Resume .... P or Esc
    Cheat menu ........ C
    Menus ............. Arrows + Enter, or mouse
    Name entry ........ Type (max 10 chars, letters/digits/spaces),
                        Enter to save, Esc to skip

GAME RULES
    - Eat all the pacgums to complete the level.
    - Super-pacgums (big blinking dots) make the ghosts edible for a
      short time: eat them for bonus points.
    - Touching a normal ghost costs one life.
    - Finish each level before the timer runs out.
    - Complete all 10 levels to win.

CONFIGURATION
    Edit config.json to change lives, pacgum density, points, the maze
    seed, the level time limit and the level sizes. Every key is
    optional; invalid values fall back to safe defaults with a warning.

    Key                          Default
    ---------------------------- ----------
    highscore_filename           highscores.json
    lives                        3
    pacgum (percent of cells)    42
    points_per_pacgum            10
    points_per_super_pacgum      50
    points_per_ghost             200
    seed                         42
    level_max_time               90
    super_pacgum_duration        8
    ghost_respawn_time           8
    levels                       array of {width, height}

HIGHSCORES
    Top 10 scores are stored in highscores.json next to the game.
