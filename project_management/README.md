# Project Management

This directory contains the project management evidence required by the
activity. Each document is listed below with a short description.

| Document                                   | Content                                                          |
|--------------------------------------------|------------------------------------------------------------------|
| [`timeline.md`](timeline.md)               | Project timeline and milestones (Gantt-style).                   |
| [`progress.md`](progress.md)               | Actual progress tracking compared to the timeline.               |
| [`analysis.md`](analysis.md)               | Project analysis and the main technical choices.                 |
| [`risk_analysis.md`](risk_analysis.md)     | Risk analysis and mitigations.                                   |
| [`team_organization.md`](team_organization.md) | Team organization, roles, decisions and issue handling.      |
| [`acceptance_test_plan.md`](acceptance_test_plan.md) | Acceptance test plan, features tested, bugs found/fixed. |
| [`blocking_points.md`](blocking_points.md) | Summary of blocking points and conflicts during the activity.    |

The project was managed with a structured, document-driven approach: a
timeline was defined first, progress was tracked against it, and every
significant decision was recorded in the analysis document so that the
final implementation can be traced back to a requirement.
